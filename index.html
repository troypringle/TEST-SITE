📚 How to Use MLGS Swipe Machine

×

🔑 First Time Setup (2 minutes)

  1. Click "API Settings" button (top right)
  2. Go to console.groq.com → Sign up free
  3. Create API key → Copy it
  4. Paste into "API Key" field → Save
  5. Edit your signature once → Lock it

⚡ Daily Workflow (30 seconds)

  1. Pick an angle from left sidebar (e.g., "💰 Money Angle")
  2. Click the button → AI generates subject + body instantly
  3. Edit if needed in the visual editor
  4. Click "Copy Full Email" (big green button)
  5. Paste into MLGS body field
  6. Grab the subject from top of pasted email → move to subject field
  7. Send!

🎯 What Each Button Does

  • 🧠 Curiosity Hook → Generates "weird trick" style subjects
  • 💰 Money Angle → Focuses on $5 commissions + income
  • ⏰ Urgency → "Before it's gone" / FOMO angles
  • 😴 Lazy Method → "Autopilot" / "while you sleep" angles
  • 📊 Proof → Results-based / testimonial style
  • 📖 Story Angle → Full email with personal story
  • 🎯 Direct CTA → Straight-to-the-point promotional email
  • ❓ Question Hook → Opens with engaging question

⚠️ Spam Word Filter

This tool automatically replaces spam trigger words:
"free" → "f-r-e-e" or "no-cost"
"money" → "income" or "earnings"
This helps your emails land in inbox, not spam.
